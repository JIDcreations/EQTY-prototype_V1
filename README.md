# EQTY Prototype

Finale app-prototype voor het bachelorproject EQTY.

## AI-assistentie

Delen van dit prototype zijn gemaakt of aangepast met behulp van AI-tools. Alle gegenereerde code werd door mij nagekeken, aangepast en geintegreerd als onderdeel van het ontwikkelproces.

Het volledige proces, de beslissingen, iteraties en het bewijs van auteurschap zijn gedocumenteerd in het bijhorende procesdocument.
